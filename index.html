    How ChronoShield Works

    Detection asks what is happening now. Forecasting asks what could happen next, to which known asset, within what horizon — using only observations available at the forecast origin.

    GraphSAGE → GRU Memory → Learned Transition → Multi-Horizon Heads

    Current prototype: deterministic simulation. The planned trained system is a GraphSAGE-GRU world-model pipeline.

    A detector classifies what is happening now. The planned ChronoShield model learns a compact network state and a transition that attempts to predict how observable network conditions evolve into the future.

    The current HTML prototype simulates this workflow using deterministic telemetry and scoring. The full project replaces the simulation scoring engine with trained forecast models.

    A forecast is committed before any later observation is revealed. Evidence supports the forecast; it does not establish causation. Evaluation must use chronological splits and inputs available at each forecast origin.
